投資初心者が、株価の動きを見ながら学べる株価分析アプリです。
「チャートや数字を見ても意味が分からない」というつまずきを減らすことを目的に作りました。

## できること

- 銘柄検索(企業名・証券コード・タグ)と、期間を選んだ終値チャートの表示
- 移動平均線(5日・25日)と出来高の表示
- 最大3社の値動き比較(開始日を100に揃えて比較)
- 関連ニュースの表示(キーワード検索、10件ごとのページ送り)
- 値動きの自動コメント(「良い傾向」「下落注意」など)
- 用語集と、全20問からランダムに出題されるクイズ

## ファイル構成

| ファイル | 内容 |
|---|---|
| `seika1.py` | 画面の試作版。株価は証券コードから作ったダミーデータを使用 |
| `seika2.py` | 完成版。株価とニュースを実データに差し替え、機能を追加 |

## 使った技術と選んだ理由

| 技術 | 選んだ理由 |
|---|---|
| Python / Streamlit | Pythonだけで画面まで作れ、計算と表示を同じコードで素早く試せるため |
| pandas / NumPy | 移動平均、前日比、ボラティリティを短いコードで計算できるため |
| yfinance | 証券コードを指定するだけで日本株の実データを取得できるため |
| RSS(Googleニュース・Yahoo!ニュース) | 追加のライブラリなしで最新ニュースを取得できるため |

## 工夫した点

- **2段階で開発**:まずダミーデータで画面を作り(`seika1.py`)、その後データ取得の部分だけを実データに差し替えました(`seika2.py`)。
- **比較しやすい表示**:銘柄比較では開始日を100に揃え、株価の水準が違う会社でも値動きを比べられるようにしました。
- **通信回数の削減**:株価は1時間、ニュースは10分、銘柄名は24時間のキャッシュを入れました。
- **取得に失敗したときの表示**:株価やニュースが取得できない場合も、エラーで止まらず案内文を表示します。

## 動かし方

Python 3.10以上が必要です。

```bash
pip install streamlit pandas numpy yfinance
streamlit run seika2.py
```

試作版を見る場合は `streamlit run seika1.py` を実行します。
